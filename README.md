# 🤖 AI GitHub PR Reviewer

An AI-powered GitHub Pull Request Reviewer built with Python, Streamlit, Groq LLM, and the GitHub REST API.

## Features

- Review GitHub Pull Requests
- AI-powered code review
- Detect bugs and code quality issues
- Performance suggestions
- Security review
- Overall PR summary
- Download review as Markdown

## Tech Stack

- Python
- Streamlit
- Groq API
- GitHub REST API

## Installation

```bash
git clone https://github.com/yourusername/github-review-agent.git

cd github-review-agent

pip install -r requirements.txt

streamlit run app.py
